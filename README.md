# EdTechBackend

## Overview
EdTechBackend is a backend service for an educational technology platform. It provides APIs and functionality to manage courses, users, learning content, and more.

## Features
- User authentication and management
- Course creation and administration
- API endpoints for interacting with the platform
- Built using **Jakarta EE**, **Spring MVC**, and **Java 21**

## Technologies Used
- **Java 21**: Core programming language
- **Jakarta EE**: For enterprise-level backend development
- **Spring MVC**: For structuring MVC architecture
- **Database**: Specify your database here (e.g., MySQL, PostgreSQL, etc.)

## Getting Started

### Prerequisites
- **Java 21** is required to run this project. Make sure it's installed on your system.
- Ensure you have a database server running (e.g., MySQL/PostgreSQL).

### Setup Instructions
1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd EdTechBackend
   ```
3. Build the project:
   ```bash
   ./gradlew build
   ```
4. Run the application:
   ```bash
   ./gradlew bootRun
   ```
5. The application will be accessible at:# EdTechBackend
